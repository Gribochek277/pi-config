feat(orchestrator): opt-in orchestration mode (no tools in normal mode)
Orchestration now behaves like plan mode: the orchestrator tools are
registered with defaultActive:false, so in normal mode none of them are
declared to the model and they cost no context tokens. The status widget
is hidden as well.

Enter/leave with /orchestrate on|off|toggle, Ctrl+Alt+O, or the
--orchestrate flag. The mode is persisted in the session and survives
resume/reload. While active, a system reminder describing the workflow and
the autonomy contract is injected before each turn; stale reminders are
dropped from context once the mode is off.

Tool visibility is managed with setActiveTools, filtering only this
extension's tools so it composes with plan mode.

Verified: without the flag no orchestrator_* names appear in context; with
--orchestrate all twelve are present.
