feat(orchestrator): project-agnostic task orchestration extension
Add agent/extensions/orchestrator: tools and commands that let an LLM
orchestrator drive parallel workers (herdr worktrees + pi agents) over a
Markdown ticket store.

Autonomous by design: no blocking UI, and mandatory decisions are made by
the orchestrator and written to a reviewable decisions file instead of
being asked of the human. Capability detection (git, herdr, ticket store,
install/check/e2e) degrades gracefully — missing features are reported
with a hint and the affected gate is skipped.

- tools: status, scan, tickets_create, start, watch, report, prompt,
  review, merge, close, abort, decide
- tickets_create reuses the to-tickets convention (vertical slices,
  blocking edges, ready-for-agent, scaffold on demand)
- /orchestrate command (status|scan|doctor|setup|init|decisions),
  TUI widget and status line
- config resolution: defaults -> detection -> user -> project
- herdr prompts are flattened to one line and submission is confirmed
  (a multi-line paste is not submitted on a freshly started agent)

Remove the unused @narumitw/pi-goal install from the local npm tree,
lockfile, and extmgr cache.

Also sync incidental local changes that were already present in the
working tree (settings, extension updates, skills, study data, extmgr
cache).
