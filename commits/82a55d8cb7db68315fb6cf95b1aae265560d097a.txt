deep-research: per-sub-question synthesis, depth param, GEO-style report
Architecture:
- Per-sub-question section synthesis: each sub-question gets its own
  section built independently, then merged — prevents context overflow
  and preserves detail for each topic
- Section merge LLM step combines sections into cohesive report
- Follow-up query generation replaces stop decision for gap discovery

Depth parameter (concise / detailed / comprehensive):
- New --depth CLI flag and tool parameter
- Depth-aware synthesis prompts with different paragraph counts
- Depth-aware consolidate prompts (exec summary + finding lengths)
- Depth-aware extraction prompts
- Default: detailed (balanced), comprehensive for max detail

Report styling (GEO guide-inspired):
- Clean typography with Inter headings + Source Serif 4 body
- Sticky sidebar TOC with scroll-spy active link highlighting
- Proper anchors on all sections and findings
- Numbered source badges with circular indicators
- Finding titles are clickable anchor links
- Better dark mode support
- Dashed border for citations section

- maxPagesPerRound: 5 → 10
- maxResultsPerSearch: 10 → 10 (unchanged)
- maxIterations: 8 → 8 (unchanged)
