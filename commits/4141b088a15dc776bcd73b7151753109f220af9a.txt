feat(orchestrator): searchable model picker and a parallel command
Worker -> model in the config editor is now a searchable list of the models
in the registry (fuzzy filter over label/description/value, Enter to pick,
the top entry clears the setting), mirroring pi's own model picker. The list
is rebuilt on each keystroke because SelectList only prefix-matches value.

Also add /orchestrate parallel <n> for a session-level parallelism change.
maxParallel was already configurable; setting it to 1 keeps orchestration
autonomous while running one worker at a time, which suits a single local
model that cannot serve several agents at once.

Verified with a stubbed-UI picker test (qwen/flash/anth/claude/default/
escape) and a live extension load.
