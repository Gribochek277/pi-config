feat(orchestrator): auto-continuation and an interactive config TUI
Auto-continuation (opt-in, off by default): while orchestration mode is on
and work remains (a tracked worker or a ready ticket), the extension injects
one continuation at the agent-settle boundary and asks pi for another model
request. It stops when nothing remains; autoContinueMax (default 50) bounds
runaway loops and a real user turn resets the counter. Toggle with
/orchestrate auto on|off or the config.

Interactive config: /orchestrate config opens a dialog-driven editor
(General, Tickets, Worker, Commands, Guards, Autonomy, plus raw JSON) and
writes .pi/orchestrator.json on "Save and close". This is the only blocking
UI, and only when the human asks for it; the orchestration loop never blocks.

Verified: extension loads with and without --orchestrate (12 tools present
only in mode), no auto-continuation fires when there is no work, and the
config editor logic passes a stubbed-UI test.
